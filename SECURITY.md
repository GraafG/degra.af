# Security Policy

## Supported versions

This repository contains the static website published at https://degra.af.
Only the current content of the `main` branch is supported.

## Reporting a vulnerability

Please report security issues privately through GitHub:

1. Go to the [Security advisories page](https://github.com/GraafG/degra.af/security/advisories).
2. Click **Report a vulnerability**.

Private vulnerability reporting is enabled, so your report stays confidential
until a fix is published. Please do not open a public issue for security
problems.

Alternatively, see [`.well-known/security.txt`](.well-known/security.txt) for a
contact address.

We aim to acknowledge reports within 7 days.
